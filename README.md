# PRODIGY_DS_05
Focuses on analyzing road accident data to identify patterns related to weather conditions, road conditions, accident severity, and time of day. The analysis helps in understanding major contributing factors behind traffic accidents and visualizing accident trends effectively.

Features Data Cleaning and Preprocessing Exploratory Data Analysis (EDA) Accident Severity Analysis Weather Condition Analysis Time-Based Accident Analysis Visualization of Accident Patterns and Hotspots

Technologies Used Python Google Colab Pandas Matplotlib Seaborn

Outcome The project provides meaningful insights into accident trends and contributing factors, helping understand how environmental and timing conditions affect road accidents.
